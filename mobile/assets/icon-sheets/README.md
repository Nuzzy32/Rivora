# Rivora glossy 3D icon sheets

Generated PNG sheets with transparent backgrounds. Existing navbar icons were used as style references.

See `manifest.json` for subjects in reading order (left to right, top to bottom). Unused final cells are empty. Weather includes the 11 requested icons plus a wind icon.

Source sheets are retained here; extracted 256px transparent PNGs in `../icons/` are bundled by Flutter and used in the app. Emergency illustrations use adjusted crop bounds because the lower row does not exactly follow the grid. Per-icon resolution is smaller than the standalone 1024px storm asset. Emergency service symbols are generic illustrations, not official agency logos.
