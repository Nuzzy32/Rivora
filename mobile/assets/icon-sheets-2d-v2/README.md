# Rivora 2D icons

Approved varied-color 2D source sheets. Reading order and names are in manifest.json, including the navbar.

Extracted 256px transparent PNGs are in ../icons/ and bundled by Flutter. Weather row boundaries and emergency lower-row columns were adjusted to match the generated sheet. Navbar report icon was trimmed to exclude a neighboring sun-ray fragment.

These replace the earlier glossy icons in the app. Older sheets remain as design source history.
